## 13/11/2026 — Journal de veille

- **Source** : [Baseline (compatibility)](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility) — site ou auteur (Mmdn_)


- **Ce que j'ai appris** : Baseline évalue la disponibilité des fonctionnalités des plateformes web sur les navigateurs les plus courants, notamment les API, les propriétés CSS et la syntaxe JavaScript.  Baseline qualifie les fonctionnalités web de largement disponibles ou récemment disponibles. Les fonctionnalités ne répondant pas aux critères de Baseline sont considérées comme ayant une disponibilité limitée. :

Baseline prend en charge les navigateurs suivants :

Apple Safari (iOS)
Apple Safari (macOS)
Google Chrome (Android)
Google Chrome (ordinateur de bureau)
Microsoft Edge (ordinateur de bureau)
Mozilla Firefox (Android)
Mozilla Firefox (ordinateur de bureau)


- **Pourquoi c'est utile pour un développeur web** : car c'est utile pour voir la compatibilité de notre site avec les navigateurs.


- **Ce que je vais faire ou vérifier** : verifier mon site pour mettre la compatibilité avec les autres navigateurs





## 30/10/2026 — Journal de veille

- **Source** : [Mots de passe : recommandations pour maîtriser sa sécurité](https://www.cnil.fr/fr/mots-de-passe-recommandations-pour-maitriser-sa-securite) — site ou auteur (Cnil)


- **Ce que j'ai appris** : Les solutions d’authentification forte ou à plusieurs facteurs fournissent une meilleure protection,
Une mauvaise gestion des mots de passe fait courir des risques aux utilisateurs sur leurs données personnelles.
Quatre facteurs de risque sont à prendre en compte :

la simplicité du mot de passe ;
l’écoute sur le réseau afin de collecter les mots de passe transmis ;
la conservation en clair du mot de passe ;
la faiblesse des modalités de renouvellement du mot de passe en cas d’oubli (cas des questions « secrètes »).


- **Pourquoi c'est utile pour un développeur web** : car c'est utile pour garder vos comptes en sécurité 


- **Ce que je vais faire ou vérifier** : j'ai déja un mots de passe complexe pour mes comptes
